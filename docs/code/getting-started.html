    Getting started

    1. Install#

    Tested on Windows with Python 3.11.9, PyTorch 2.5.1 (CUDA 12.1) and an NVIDIA RTX 4060 Laptop GPU.

    pip install -r requirements.txt

    Install the PyTorch build that matches your CUDA version from pytorch.org.

    2. Get the data#

    The datasets are not included in the repository. Download them and place them as shown.

    Dataset Download Put it in It should contain
    CBIS-DDSM (JPEG version) Kaggle · original DICOM release on TCIA data/CBIS-DDSM/ csv/ and jpeg/
    INbreast On request from the dataset authors (paper) data/INbreast/ AllDICOMs/ and INbreast.csv (or .xls)

    If your data is stored somewhere else, point to it with environment variables instead:

    $env:CBIS_DDSM_DIR = "D:\datasets\CBIS-DDSM"
$env:INBREAST_DIR  = "D:\datasets\INbreast"

    export CBIS_DDSM_DIR=/data/CBIS-DDSM
export INBREAST_DIR=/data/INbreast

    3. Run the experiments#

    Run everything from the repository folder, starting with the main experiment. Later scripts reuse its results and its image cache.

    # Training
python experiments/main_cbis_ddsm.py
python experiments/method_comparison.py
python experiments/calibration_experiment.py
python experiments/inbreast_validation.py --data-root data/INbreast
python experiments/shortcut_strength_sweep.py --seeds 5
python experiments/backbone_density_variants.py --seeds 5
python experiments/weight_and_grl_sweeps.py --study distcorr
python experiments/weight_and_grl_sweeps.py --study camreg
python experiments/weight_and_grl_sweeps.py --study grl
python experiments/full_weight_grid.py

# Analysis (no training)
python analysis/density_split_report.py
python analysis/mask_audit.py --full-res
python analysis/calibration_analysis.py calibration --dir outputs/calibration_experiment
python analysis/density_probe_metrics.py --dir outputs/calibration_experiment
python analysis/tables_and_figures.py
python analysis/paper_figures.py

    Handy options#

    Script Option What it does
    main_cbis_ddsm.py, method_comparison.py --seeds N Use only the first N seeds
    Other experiment scripts --dry-run Show the planned runs and data sizes without training
    Other experiment scripts --smoke A quick one-seed run to test the setup
    Other experiment scripts --help List every option

    Working on this website#

    The website is plain HTML, CSS and JavaScript in the docs/ folder, with no build step.

    • Preview it: run python -m http.server -d docs 8000 and open http://127.0.0.1:8000, or open docs/index.html directly.
    • Edit a page: each page is one HTML file, for example docs/results/main.html. Styles are in docs/assets/css/site.css and behaviour in docs/assets/js/site.js.
    • Publish it: on GitHub, open Settings → Pages, choose Deploy from a branch, and select the main branch and the /docs folder.

    Adding the figures#

    The figure slots on this site show a placeholder until the image file exists. Save your figures in docs/assets/figures/ with these names:

    File name Where it comes from Shown on
    architecture.png Your pipeline diagram (rename architecture 2.png) Home, Method
    dccam_qualitative_gradcam.png outputs/main_experiment/ Main comparison
    forest_plot_main.png outputs/paper_figures/ Main comparison
    shortcut_and_weight_sweeps.png outputs/paper_figures/ Loss weights and shortcut strength
    grl_configurations.png outputs/paper_figures/ Adversaries and published methods
