    Code

    Output files

    Each script writes to its own folder under outputs/. The tables below list every file and what it contains. Checkpoints (ckpt/), image caches (*.pkl) and INbreast images are not included in the repository.

    main_experiment/#

    Main CBIS-DDSM experiment: five strategies over 13 seeds.

    Created by: python experiments/main_cbis_ddsm.py

    File Contents
    dccam_cbis_results.csv per-seed results (Tables 4 and 5)
    power_analysis.csv seeds needed for 80% power
    dccam_forest_plot.png paired differences against the baseline
    dccam_qualitative_gradcam.png Grad-CAM examples (Fig. 2)
    dccam_cbis_comparison.png summary bar chart
    distcorr_sensitivity_sweep.csv distance-correlation weight 3-7 sweep (Section 4.2)
    distcorr_sensitivity_sweep.png
    run_manifest.json seeds, library versions and determinism settings

    method_comparison/#

    All strategies including mi_min, the MI diagnostic, published methods and a first INbreast sweep.

    Created by: python experiments/method_comparison.py

    File Contents
    combined_10arm_results.csv published methods next to the studied strategies (Table 7)
    combined_10arm_summary.csv
    benchmark_baselines_results.csv MINE, non-linear adversary, Group DRO and JTT
    benchmark_baselines_stats.csv paired statistics for those methods
    benchmark_baselines_power_analysis.csv
    benchmark_baselines_forest_plot.png
    dccam_cbis_results.csv six-strategy run (includes mi_min)
    power_analysis.csv
    mi_min_club_diagnostic.csv CLUB estimate against a fresh density probe
    mi_min_club_diagnostic.png
    inbreast_external_validation_results.csv first INbreast sweep (the paper uses inbreast_validation/)
    inbreast_external_validation_stats.csv
    inbreast_external_validation_summary.csv
    inbreast_external_validation_power.csv
    inbreast_external_validation_forest.png
    run_manifest.json

    calibration_experiment/#

    13-seed run that also saves probabilities and checkpoints: calibration, decision threshold, SAS under perturbed masks and the balanced density probe.

    Created by: python experiments/calibration_experiment.py, then analysis/calibration_analysis.py and analysis/density_probe_metrics.py

    File Contents
    results.csv one row per run, with group sizes and SAS under dilated/eroded masks
    summary_by_tag.csv
    paired_vs_baseline.csv
    calibration_per_run.csv
    calibration_summary.csv Table 8
    calibration_paired_vs_baseline.csv
    sas_mask_sensitivity.csv SAS under dilated / eroded masks
    sas_mask_sensitivity_summary.csv
    probe_balanced_per_run.csv
    probe_balanced_summary.csv balanced accuracy and AUROC of the density probe
    probe_balanced_paired.csv
    reproduce_vs_main.csv
    reproduce_summary.csv
    reliability_diagram_main.png
    threshold_shift_main.png
    epoch_history.csv
    probs/ saved test / validation probabilities
    logs/ training logs
    ckpt/ model checkpoints, not uploaded (see .gitignore)
    run_manifest_calibration_experiment.json

    inbreast_validation/#

    INbreast (full-field digital mammography) replication, 13 seeds.

    Created by: python experiments/inbreast_validation.py --data-root data/INbreast

    File Contents
    results.csv INbreast row of Table 6
    summary_by_tag.csv
    paired_vs_baseline.csv
    cohort_summary.txt 192 images from 102 patients
    cohort_density_counts.csv
    per_seed_group_counts.csv
    calibration_summary.csv
    calibration_paired_vs_baseline.csv
    sas_mask_sensitivity.csv
    probs/, logs/
    ckpt/ not uploaded
    inbreast_image_cache.pkl not uploaded (contains INbreast images)
    run_manifest_inbreast_validation.json

    shortcut_strength_sweep/#

    Injected correlation from r = 0 to 0.62, with training-size and class-prior controls (5 seeds).

    Created by: python experiments/shortcut_strength_sweep.py --seeds 5

    File Contents
    results.csv one row per run
    condition_summary.csv used for Fig. 4a
    dose_response.csv
    dose_response.png
    paired_vs_baseline.csv
    control_comparison.csv size, class-prior and correlation contrasts
    split_log.csv training-fold size, achieved r and class prior per seed
    import_reproducibility.csv
    strategy_by_condition.png
    run_manifest.json
