    Engineering notes

    Things learned while running the experiments, written down so the results can be repeated and built on.

    Getting the same result twice on a GPU#

    You need both settings

    Setting the random seed is not enough on a GPU. Runs only repeat exactly with both cudnn.benchmark = False and cudnn.deterministic = True, plus CUBLAS_WORKSPACE_CONFIG=:4096:8 set before CUDA starts. Setting only one of the two does not work.

    • The core pipeline switches cudnn.benchmark on when it loads, so the experiment scripts apply the safe settings after loading it.
    • With these settings, a second run of the main comparison matched the first to four decimal places for the baseline, distance correlation, CAM regularization and both fixes.
    • One exception: method_comparison.py loads core_pipeline_legacy, which switches cudnn.benchmark back on. Rerunning that script can change the last decimal place.
    • Every run saves a run_manifest*.json file with its seeds, settings, library versions, GPU and these flags.

    Long runs that can stop and continue#

    Multi-seed runs take a long time on a laptop GPU, and a CUDA crash in the middle of an early run showed that results must be saved as you go. Now:

    • results are saved after every finished run, and a script that stops carries on from where it left off;
    • saved models and saved test probabilities let you redo the analysis without training again.

    Running on Windows#

    A few settings keep training stable on Windows:

    • cv2.setNumThreads(0), so OpenCV threads do not clash with PyTorch;
    • num_workers=0 in the data loaders;
    • the current torch.amp functions for mixed precision.

    Image cache#

    Reading and masking thousands of mammograms is the slowest part of a first run. Each image is resized to 224 × 224 and masked once, then stored in outputs/cbis_image_cache.pkl (INbreast has its own cache). Later runs load it in seconds. Cache files are kept out of Git.

    Statistics with few runs#

    With n paired runs, the smallest possible two-sided Wilcoxon p-value is \(2 \times 0.5^{n}\). That is about 0.0002 for 13 runs but 0.0625 for 5. The 5-run studies therefore rely on confidence intervals and on how many runs agree, not on p-values.
