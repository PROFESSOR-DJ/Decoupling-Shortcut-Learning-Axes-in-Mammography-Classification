    Repository structure

    mammography-shortcut-axes/
├── src/                          shared code used by every script
│   ├── core_pipeline.py          data, breast masks, shortcut, network, training, evaluation
│   ├── core_pipeline_legacy.py   older copy of the pipeline, used by external_validation.py
│   ├── external_validation.py    INbreast loading, DICOM reading, external-dataset runs
│   ├── published_baselines.py    MINE, two-layer adversary, Group DRO and JTT
│   ├── experiment_utils.py       data splits, single runs, saving results, statistics
│   └── paths.py                  where data is read from and results are written to
├── experiments/                  scripts that train models
├── analysis/                     scripts that only read data or results
├── data/                         datasets go here (not included)
├── outputs/                      one folder per script
├── docs/                         this website (HTML, CSS and JavaScript)
├── requirements.txt
└── README.md

    Shared code#

    File What it handles
    core_pipeline.py Reading CBIS-DDSM, the image cache, the breast mask, adding the shortcut, the network (ResNet-18 with a cancer head and a density head), the five training methods, Grad-CAM, SAS, the density probe, and the statistics
    core_pipeline_legacy.py An older version of the same pipeline, still needed by external_validation.py
    external_validation.py Reading INbreast and its DICOM files, and running the main comparison on another dataset
    published_baselines.py The MINE penalty, the two-layer adversary, Group DRO and JTT, trained on the same splits
    experiment_utils.py Patient-grouped splits, shortcut settings, one train-and-test run, saved probabilities, a results file that lets stopped runs continue, and paired statistics
    paths.py Data and output folders; can be changed with CBIS_DDSM_DIR and INBREAST_DIR
