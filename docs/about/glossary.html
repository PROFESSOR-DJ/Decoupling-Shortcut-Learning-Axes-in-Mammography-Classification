    Glossary

    Short forms#

    Term Meaning
    ACR American College of Radiology (density grades used in INbreast)
    AUROC Area under the ROC curve: how well a model ranks cancers above benign cases (0.5 = chance, 1 = perfect)
    BI-RADS The standard system radiologists use for reporting; its density grades run from A to D
    CAM Class activation map: a heat map of which image areas drove the prediction
    CBIS-DDSM A curated public collection of scanned film mammograms
    CI Confidence interval
    CLUB A method that reduces mutual information between features and an attribute
    DistCorr / dCor Distance correlation: a measure of any kind of dependence between two variables
    ECE Expected calibration error: how far predicted probabilities are from real frequencies
    FDR False discovery rate
    GAP Global average pooling
    Grad-CAM A common way of drawing a CAM heat map from a trained network
    GRL Gradient reversal layer: the core of adversarial removal
    Group DRO A training method that focuses on the worst-off group
    JTT Just Train Twice: retrains with extra weight on the examples a first model got wrong
    MI Mutual information
    MINE A neural estimator of mutual information, used here as a penalty
    SAS Spurious attribution score: the share of the heat map outside the breast
    SD Standard deviation
    TCIA The Cancer Imaging Archive, which hosts CBIS-DDSM

    Key ideas#

    Shortcut
    An easy cue that happens to go along with the label in the training data, which the model uses instead of the real signal.
    Aligned group
    Test cases that fit the shortcut: a dense cancer, or a non-dense benign case.
    Conflicting group
    Test cases that break the shortcut: a non-dense cancer, or a dense benign case. A shortcut-reliant model struggles here.
    Group gap
    AUROC on the aligned group minus AUROC on the conflicting group. The main measure in this work; smaller is fairer.
    Density probe
    A simple classifier trained on the model's features to guess density. If it guesses well, density is still in the features.
    Adding the shortcut
    Sampling the training data so that density and cancer go together (r ≈ 0.6), while the validation and test data stay untouched.

    Symbols#

    Symbol Meaning
    \(\alpha\) Significance level of a test (here 0.05)
    \(\mathrm{AUROC}_a\) AUROC on the aligned group
    \(\mathrm{AUROC}_c\) AUROC on the conflicting group
    \(\mathrm{CAM}_i\) Heat-map value at pixel \(i\) (normalized, never negative)
    \(\Delta_{\text{gap}}\) Group gap, \(\mathrm{AUROC}_a - \mathrm{AUROC}_c\)
    \(J\) Youden's J: sensitivity + specificity − 1
    \(\lambda\) Reversal strength, or the weight of a penalty
    \(\lambda_{\max}\) Highest reversal strength
    \(M_i\) Breast mask at pixel \(i\): 1 inside, 0 outside
    \(n\) Number of paired runs
    \(p\) Wilcoxon signed-rank p-value
    \(r\) Correlation between density and cancer
    \(w\) Weight of the adversarial loss
